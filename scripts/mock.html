dsh-rfiles 客户端联调页

这个页面由 scripts/mock-server.mjs 提供，用内存假数据模拟 CONTRACT.md §1 的全部路由， 便于在桌面或手机浏览器里手工验证 lib/client.js，不需要启动 DSH。

直连模式 直连 /api 远程模式 /remote/api

远程模式会发布 __DSH_REMOTE_CHANNEL_BOOT__，让下载链接带上 /remote 前缀； mock server 会把 /remote/api/* 透传到同一套处理逻辑。

手工验证清单

  • 点右下角「文件」按钮打开面板；会话下拉应有两个 mock 会话，默认选中「示例会话 B（最新）」。
  • 上传：选文件后按 8 MiB 分块 PUT，进度条累计；断网/失败后点「重试」应复用 uploadId 续传。
  • 「只存入工作区」模式：完成后切到「下载」标签页，.uploads/ 下能看到刚上传的文件。
  • 下载：点 demo.bin（1 MiB）应触发原生下载；⤓ 按钮走 fetch+blob 兜底保存。
  • 「下载会话日志 ZIP」返回 application/zip；「通过请求保存」走 fetch。
  • Range：curl -r 0-1023 -D- http://127.0.0.1:4399/api/rfiles.download?sessionId=mock-session-b&path=demo.bin 应为 206。
  • 错误提示：把 ?remote=1 页面的下载链接换成缺 sessionId 的地址，应显示中文错误。

mock 数据

  • readme.txt、demo.bin（1 MiB）、示例图片.png
  • examples/notes.md（验证面包屑）
  • exports/session-log.zip（假日志 ZIP）
  • .uploads/（workspace 模式上传的落点）

直接双击打开本文件不会生效：客户端脚本由 mock server 在返回 HTML 时内联注入。 请先运行 node scripts/mock-server.mjs --port 4399，再访问 http://127.0.0.1:4399/mock.html。
